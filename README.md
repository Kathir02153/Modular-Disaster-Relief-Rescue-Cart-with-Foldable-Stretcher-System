## Overview

A modular rescue cart designed for disaster-relief scenarios, featuring an integrated foldable stretcher system for rapid patient transport in emergency and post-disaster environments. The design focuses on portability, quick deployment, and ease of use in challenging terrain where conventional stretchers or wheeled carts fall short.

## Key Features

- **Modular construction** — cart and stretcher components can be assembled/disassembled quickly for transport and storage
- **Foldable stretcher system** — collapses for compact storage, deploys rapidly during emergencies
- **Terrain adaptability** — designed for use in disaster-affected areas with uneven or obstructed ground
- **Lightweight, rescue-optimized frame** — built for fast, low-effort maneuvering by first responders
